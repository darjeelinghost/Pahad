# PAHAD Standalone Supporting Pages

These pages are aligned to the approved PAHAD homepage visual identity and navigation. Each page contains its own CSS and JavaScript. No external stylesheet or JavaScript file is required. The Google Fonts import has been removed; system fonts and Georgia provide reliable offline typography.

Upload all HTML files, `manifest.webmanifest`, `sw.js`, and `pahad-app-icon.svg` into the same root folder as your existing `index.html`. Do not replace `index.html`.

The navigation and official PAHAD emblem match the current homepage. The Install control uses the browser's native PWA prompt when available and otherwise explains the manual install route.
